Grape Disease Weather-Based Forecasting System

Five-day weather forecast · Threshold-based disease favourability assessment

1. Forecast location and data source

Weather data source: Open-Meteo forecast API. Internet access is required to fetch updated data.

2. Five-day weather forecast and manual inputs

Minimum, average and maximum temperature and relative humidity, rainfall and solar radiation are fetched from the API. Disease thresholds are evaluated using daily average temperature and daily average relative humidity, not the min–max range.

4. Interpretation and limitations

  • Temperature thresholds are evaluated using the API's daily average temperature. Minimum and maximum temperatures are displayed for reference only and do not determine disease favourability.
  • Relative-humidity thresholds are evaluated using the API's daily average RH. Minimum and maximum RH are displayed for reference only and do not determine disease favourability.
  • Rainfall thresholds use the forecast daily precipitation total. Leaf wetness and continuous rainfall duration are excluded. Anthracnose rainfall is not assessed because its original criterion was continuous rain duration.
  • Powdery mildew has no leaf-wetness threshold in the values supplied, so leaf wetness is not used in that assessment.
  • “Favourable” means all entered/applicable threshold conditions are met. It is a weather-based favourability indicator, not a prediction that infection or symptoms will certainly occur. Inoculum, crop stage, cultivar, canopy conditions and fungicide history are not included.
  • Solar radiation is displayed for monitoring but is not used in disease classification because no disease-specific threshold was supplied.
